# Sten-Sax-Påse

Hej! Jag heter Anton Smedberg, och jag är riktigt glad över att dela mitt Sten-Sax-Påse-spel med dig. Detta är ett klassiskt spel där du kan testa dina strategiska färdigheter mot en dator. Målet är att vara den första att nå 5 poäng. Kan du slå datorn?

## 🎮 Hur man Spelar

- När du startar spelet kommer du att mötas av en trevlig introduktion.
- Ditt mål är att välja "Sten", "Sax", eller "Påse".
- Du gör ditt val genom att skriva den första bokstaven: `s` för Sten, `x` för Sax, och `p` för Påse.
- Datorn gör sitt val samtidigt, och resultatet visas direkt.
- Första spelaren till 5 poäng vinner spelet, och du får möjligheten att spela igen eller avsluta.

## 📋 Funktioner

- **Färgglad Text och Emojis**: Spelet använder sig av färger och emojis för att göra spelet mer engagerande och roligt att spela.
- **Smart Input Validering**: Spelet validerar dina inmatningar och säkerställer att endast giltiga val accepteras.
- **High Score**: Spelet håller reda på ditt bästa resultat under en omgång, så du alltid kan se hur bra du har spelat.
- **Replay Funktion**: Efter varje omgång kan du välja att spela igen utan att behöva starta om spelet.
- **Anpassningsbara Regler**: Du kan enkelt justera antalet poäng som krävs för att vinna spelet genom att ändra `vinnarpoäng` när du skapar ett nytt spelobjekt.
