# Academy Coursework — Anton Smedberg

This is where I keep the projects I built while learning software engineering between 2023 and 2026. Most of these are course assignments and exercises — not polished products, but each one taught me something concrete.

I organized everything by language so it's easy to follow how my skills developed over time.

## What's inside

| Folder | What it covers | Projects |
|--------|---------------|----------|
| [`java-android/`](./java-android) | Java, Android, and a couple of web apps built with Firebase | 10 |
| [`javascript-typescript/`](./javascript-typescript) | JavaScript and TypeScript projects, from 3D visualizations to full-stack apps | 7 |
| [`python/`](./python) | Python exercises, data analysis, machine learning, and a few small tools | 12 |
| [`kotlin/`](./kotlin) | Kotlin exercises from early Android studies | 1 |
| [`swift/`](./swift) | SwiftUI assignments from when I first started with iOS | 2 |

## A rough timeline

- **2023** — Started with Java and Android. Built simple apps, learned OOP, got comfortable with the command line.
- **2024** — Moved into web development. Built full-stack apps with React, started experimenting with Python and AI/ML.
- **2025** — Discovered Swift and iOS development. This is where things started clicking for me.
- **2026** — Went deep on Swift, SwiftUI, Swift Concurrency, and Metal. Built the projects you can find in my main profile.

## Why I keep this public

It's a honest record of how I learned. The code isn't always pretty, and some of these projects are rough around the edges — but that's the point. This is what real learning looks like.

If you want to see my best work, check out my [main profile](https://github.com/antonsmedberg) where I keep the projects I'm actually proud of.
