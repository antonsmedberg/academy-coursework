# Java & Android

These are the Java and Android projects I built during 2023–2024, back when I was still figuring out how mobile apps actually work. Most of these are course assignments, but they cover a fair bit of ground — from Android lifecycle management to a full Scrum board with Firebase.

| Project | What I built |
|---------|-------------|
| `android-weather-api` | Android weather app that pulls from a REST API |
| `flutter-mobile-app` | My first attempt at cross-platform with Flutter |
| `android-lifecycle` | Exercise focused on Android activity lifecycle |
| `android-shake-detector` | Android app using the accelerometer to detect shakes |
| `javafx-todo-app` | To-Do management system built with JavaFX |
| `java-vehicle-rental` | Console-based Java vehicle rental system |
| `java-student-management` | Java file-based student management system |
| `scrum-board-firebase` | React Scrum board backed by Firebase |
| `html-dice-game` | Simple HTML/CSS/JavaScript dice game |
| `movie-database-app` | React movie database pulling from TMDB API |

The naming got cleaned up later. Some of these I'm genuinely pleased with, others are pretty rough. That's how it goes.
